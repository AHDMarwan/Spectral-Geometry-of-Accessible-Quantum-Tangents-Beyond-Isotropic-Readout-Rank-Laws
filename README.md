# Spectral Geometry of Accessible Quantum Tangents

This repository contains the reproducibility suite and manuscript sources for the measurement-accessible tangent-geometry study.

## Advanced Quantum Technologies submission

The final Wiley/AQT-formatted submission source is in [`paper/aqt/main.tex`](paper/aqt/main.tex). The file contains the complete article, consolidated references, and Supporting Information. Template support is kept in `paper/aqt/template_support.zip`; figures are reused from `paper/manuscript/figures/`.

For the full research reproducibility record, experiment protocols, data products, and legacy manuscript materials, see the directories and documentation in this repository.
