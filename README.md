# Spectral Geometry of Accessible Quantum Tangents

Reproducibility and falsification-oriented numerical experiments for *Spectral Geometry of Accessible Quantum Tangents: Beyond Isotropic Readout-Rank Laws*.

This repository is being rebuilt from the original research notebooks into a reproducible experiment suite. The design principle is falsification first: reported conclusions are accepted only when they survive independent seeds, circuit families, depth/size sweeps, estimator diagnostics, and explicit negative controls.
