# Data and software availability plan

GitHub Actions uploads raw per-circuit CSV files, spectra, random-orientation controls, merged tables, and analysis outputs as immutable workflow artifacts. The repository contains all source code, profiles, and fixed seeds required to regenerate them.

For journal submission, create a versioned release and archive that release plus the final numerical artifacts in a persistent research repository such as Zenodo. Cite the resulting DOI in the manuscript's Data Availability Statement. Do not cite only a moving branch name when a permanent release/DOI is available.
